## 🚀 Features

- ⚡ Animated particle background with mouse interaction
- 🔴 Glitch effect hero section with typing animation
- 📊 Animated skill bars & achievement counters
- 🛸 Project vault with live/WIP status indicators
- 💼 Internship & education timeline
- 📬 Contact form with social links
- 📱 Fully responsive with hamburger mobile menu
- 📄 CV download button
- 🖱️ Custom cursor with hover effects

---

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| Framework | React.js |
| Animations | Framer Motion |
| Typing | react-type-animation |
| Counter | react-countup |
| Icons | react-icons |
| Fonts | Orbitron · Rajdhani · Share Tech Mono |

## 📦 Getting Started

```bash
# Clone the repo
git clone https://github.com/Srivignesh12345/portfolio.git

# Navigate into the folder
cd portfolio

# Install dependencies
npm install

# Start development server
npm start
```
